# GreenShelf

A free, friendly book-sharing platform for students, parents, and schools in Oman.

Live at: [greenshelf.online](https://greenshelf.online)

Built by [Hitesh Gurnani](#) and [Anshul Date](#).

## Stack

- Vanilla HTML / CSS / JavaScript
- [Supabase](https://supabase.com) — auth, database, storage
- [Vercel](https://vercel.com) — hosting
- PWA-enabled (installable on iOS, Android, desktop)
